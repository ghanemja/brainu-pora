# State-space model

A **state-space model** represents a physical system using first-order ODEs in matrix form, capturing internal state variables.

## Form

ẋ = Ax + Bu
y = Cx + Du

## Concepts

- A = system matrix
- B = input matrix
- C = output matrix
- Eigenvalues of A determine [[Lyapunov_stability]]
