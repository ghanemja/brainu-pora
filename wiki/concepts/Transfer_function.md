# Transfer function

A **transfer function** G(s) is the Laplace-domain ratio of output Y(s) to input U(s) for a linear time-invariant system.

## Form

G(s) = Y(s)/U(s) = (b_m·s^m + ... + b_0) / (a_n·s^n + ... + a_0)

## Use

- Pole locations determine [[Lyapunov_stability]]
- Bode plots for frequency response
- Root locus for [[PID_control]] tuning
